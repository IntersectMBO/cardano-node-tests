# Commits

Run `git commit` with `-n`. Write the commit message using the commitizen convention, with both a title and a semi-detailed description. Keep the title under 50 characters, followed by a blank line and a body explaining the main changes and why they were made. Do not use a title-only message. Wrap the body at 72 characters. Format the complete message as a gitcommit code block.

Do not add Co-Authored-By lines to commit messages.
