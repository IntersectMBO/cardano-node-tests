About these numbers

Few runs per version
Most versions were synced once, so run-to-run noise is not measured. Treat small deltas as unconfirmed until a version has been synced twice.
The chain grows
Runs are weeks apart on a longer chain. Chain size is in the run facts; seconds per GB of chain compares runs of different lengths.
Slots per second
An era's slot count divided by its sync time. It does not depend on the era's length, so it compares across eras and runs.
Memory
The RAM graph shows the heap. RSS peak and end are in the run facts.
Slow epochs
Epochs that took far longer than the epochs around them. An epoch slow in every run is a property of the chain, not of a version.
